# Reglas del Proyecto (AGENTS.md)

- **Control de Versiones e Incremento Continuo**: Cada vez que se agregue una nueva característica, funcionalidad o ajuste al proyecto, se debe incrementar la numeración de la versión (en `package.json`, `DOCUMENTACION.md`, guiones y fuentes de presentación) para no perder el hilo de las actualizaciones.
- **Idioma**: Respuestas, documentación, archivos e instrucciones redactados en español neutro.
- **Explicación Detallada de Cambios**: Explicar siempre detalladamente cualquier modificación en los archivos originales del proyecto antes de aplicarla.
